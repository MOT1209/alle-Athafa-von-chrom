# Chrome Web Store Listing — videoKING AI

## Title
videoKING AI — Local-first Video Knowledge

## Summary
Turn videos into searchable knowledge with local AI: summaries, chat,
transcripts, translations, and learning tools. No paid APIs required.

## Description
videoKING AI runs entirely on your device using Ollama. Capture YouTube
transcripts, generate schema-validated summaries, chat with cited timestamps,
translate transcripts (AR↔EN and more), create study material, transcribe
audio with Whisper, and generate original Arabic kids stories. All data stays
local.

## Permissions
- storage, alarms
- host: localhost:11434 (Ollama), 127.0.0.1:11434
- optional: localhost:8178 (Whisper), 127.0.0.1:8178, localhost:5000 (Piper)
